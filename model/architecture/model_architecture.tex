\section{Overview}
The current production model is the Motion-FPN + Cross-Attention Kinematic V2 planner, implemented in \texttt{model/CreateModel.py}.
It predicts future ego kinematics from two consecutive front-camera frames and optional ego-history context.
The model is built as a motion-aware image encoder plus a stepwise recurrent decoder that performs cross-attention over spatial memory at every prediction step.

\section{Architecture Blocks}

\subsection{Low-Level Utility Blocks}
\begin{itemize}
    \item \textbf{ConvGNAct}: convolution + GroupNorm + SiLU.
    \item \textbf{SEBlock}: squeeze-excitation channel recalibration.
    \item \textbf{Residual}: two ConvGNAct layers with residual skip, optional SE.
    \item \textbf{FiLM}: feature-wise affine conditioning from ego context.
\end{itemize}

\subsection{MotionBackbone (Shared Weights)}
Both frames are encoded by the same backbone.
\begin{itemize}
    \item Stem: ConvGNAct(3 to base, stride 2) + Residual(base, SE).
    \item Stage1: ConvGNAct(base to 2 base, stride 2) + Residual(2 base, SE).
    \item Stage2: ConvGNAct(2 base to 3 base, stride 2) + Residual(3 base, SE), output at $1/8$ scale.
    \item Stage3: ConvGNAct(3 base to 4 base, stride 2) + Residual(4 base, SE), output at $1/16$ scale.
\end{itemize}

\subsection{MotionFpnEncoder}
Per scale, the encoder builds motion-aware features from
\[
[f_t,\;f_{t-1},\;f_t-f_{t-1}]
\]
then applies 1x1 fusion convolutions, top-down FPN fusion, and a final ConvGNAct.

Key details:
\begin{itemize}
    \item Two motion scales are fused: $1/8$ and $1/16$.
    \item Normalized coordinate channels $(x,y)$ in $[-1,1]$ are appended.
    \item FiLM uses ego-context to modulate the final fused map.
    \item Optional motion-map output is available for visualization.
\end{itemize}

Output tensor shape is $(B,\text{featDim}+2,H/8,W/8)$.
For 360x640 input, this is approximately $(B,\text{featDim}+2,45,80)$.

\subsection{EgoStateEncoder}
A single-layer GRU encodes ego-history $(B,8,3)$ into a context vector $(B,256)$.
During training, ego context uses dropout (default \texttt{egoDropoutProb=0.15}) to reduce ego-only shortcut behavior.

\subsection{CrossAttentionDeltaKinematicDecoder}
This decoder replaced the old parallel transformer-vector head.
It is autoregressive and predicts \textbf{delta kinematic updates} step by step.

Per prediction step:
\begin{itemize}
    \item Spatial memory: encoder map is projected to hidden dimension, flattened, and layer-normalized.
    \item Time embedding: built from pair $(t_k,\Delta t_k)$.
    \item Query token uses recurrent hidden state, ego context, previous kinematic state, and time embedding.
    \item Cross-attention reads from spatial memory.
    \item A GRU updates recurrent state and a delta head outputs $(\Delta v,\Delta \dot{\psi})$.
    \item Current state is accumulated autoregressively.
\end{itemize}

Teacher forcing is one-step lagged to avoid current-step target leakage.
Attention maps can be returned for analysis and visualization.

\section{Temporal Rollout and Trajectory Integration}
The model outputs speed and yaw-rate over non-uniform future offsets.
Training and inference utilities integrate these kinematics as:

\[
\psi_t = \psi_{t-1} + \dot{\psi}_t\,\Delta t_t
\]

\[
x_t = x_{t-1} + v_t\sin(\psi_t)\,\Delta t_t,
\qquad
y_t = y_{t-1} + v_t\cos(\psi_t)\,\Delta t_t
\]

where local coordinates are right-forward in meters.

\section{Summary}
The current model is a motion-conditioned, ego-aware, cross-attention recurrent planner.
Compared to the legacy transformer-vector formulation, V2 shifts to kinematic-state rollout with per-step spatial re-attention, which improves temporal consistency and makes attention diagnostics more interpretable.
